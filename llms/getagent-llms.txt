# GetAgent

> GetAgent is a UK PropTech company (getagent.co.uk) that helps home sellers compare and choose estate agents using independent performance data such as sold prices, time-to-sell, and fees. Backed by 500 Global and Seedcamp. Profiled in the API Evangelist network as a portfolio lead; no public API or developer portal was discoverable at profiling time.
